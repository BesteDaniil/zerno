# Папка для изображений

Сейчас сайт использует фото напрямую с **Unsplash** (быстрые CDN-ссылки),
поэтому папка `images/` может оставаться пустой — сайт работает как есть.

## Как заменить на свои фото

1. Положите файлы сюда, например: `images/hero.jpg`, `images/about.jpg`.
2. Замените ссылки в коде на **относительные пути** (без ведущего слэша!):

   **Первый экран** — в `css/style.css`, селектор `.hero`:
   ```css
   background: linear-gradient(...),
               url('../images/hero.jpg') center/cover no-repeat;
   ```
   (из CSS путь идёт от папки `css/`, поэтому `../images/...`)

   **Блок «О нас»** — в `index.html`, тег `<img class="about__media">`:
   ```html
   <img src="images/about.jpg" alt="..." />
   ```
   (из `index.html` путь — просто `images/...`)

## Рекомендации по фото
- Первый экран (hero): горизонтальное, ~1600×1000, до ~300 КБ.
- «О нас»: вертикальное, ~1000×1250.
- Формат: JPG (фото) или WebP для меньшего веса. Сжать можно на squoosh.app.
